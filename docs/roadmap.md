# Roadmap

## Current release-candidate priorities

- validate clean offline install, upgrade, redeploy, and both uninstall choices;
- expand real Windows coverage without using real user dictionaries as fixtures;
- keep Public Baseline V1 portability tests green on Windows PowerShell 5.1 and
  PowerShell 7;
- publish the first unsigned RC with SHA-256 and build metadata; and
- apply to SignPath Foundation only after the public repository and release are
  independently verifiable.

## Later work

- address the cosmetic ASCII-mode icon limitation;
- improve diagnostics without logging input contents or personal paths;
- evaluate optional input features only with an explicit privacy and licensing
  review; and
- add signing only after SignPath Foundation acceptance and manual approval
  controls are in place.

The project does not plan telemetry, cloud dictionaries, accounts, advertising,
background clipboard monitoring, or automatic cross-database UserDB migration.
